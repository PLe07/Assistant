# id | nom | pluriel | rayon | unité | formats vendus | allergènes | catégorie | saison | jours | options | synonymes
#
# - unité de base des recettes : g, ml ou p (pièce) ; `p=120g` donne le poids d'une pièce (conversions).
# - formats : quantité (en unité de base) @ prix en euros [= libellé], séparés par des virgules ; `vrac` : au poids.
# - allergènes : parmi les 14 réglementaires ; « selon les marques » compte comme présent (prudence).
# - saison : mois de saison en France (calendriers ADEME / Interfel) ; `-` : pas un fruit ou légume ;
#   `imp` : importé (jamais de saison en France) ; l'option `sans_saison` (aromates, alliacées, agrumes en filet)
#   l'exclut du calcul des « produits de saison » (on en met trop peu pour qu'il compte).
# - jours : combien de temps il se garde une fois acheté (frigo pour le frais, placard pour le reste).
# - options : placard (dans le placard de base), congeler (viande ou poisson frais, à congeler en rentrant s'il sert
#   plus tard), hache (viande hachée), trempage=12 (légumineuse sèche, heures de trempage), non_vege (contient un
#   produit animal caché : présure, poisson…), animal (produit animal non carné : pas vegan).
#
# Prix : relevés indicatifs d'enseigne de supermarché en France, marques distributeur, automne 2026.
